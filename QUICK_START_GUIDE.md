# 🚀 Skill Tracker - Quick Start Guide

## ⚡ 5-Minute Setup

### 1. Access the App
```
URL: http://localhost:5019/SkillRoadmap
```

### 2. Create Your First Skill (30 seconds)
1. Click "➕ Add New Skill"
2. Fill in:
   - **Skill Name**: JavaScript
   - **Goal Level**: Beginner
   - **Total Days**: 60
   - **Daily Minutes**: 60
   - **Start Date**: Today
3. Click "✨ Create Skill"

### 3. Complete Today's Task (15 seconds)
1. You'll see the Dashboard
2. In "Today's Progress" section:
   - Enter minutes spent: 60
   - Add notes (optional): "Learned variables"
   - Click "✅ Mark Today as Complete"
3. Get motivational message! 🎉

### 4. Track Your Progress
- View beautiful charts 📊
- Check your streak 🔥
- Monitor completion percentage
- Navigate through days

---

## 🎯 Main Features

### Skills Overview
- **URL**: `/SkillRoadmap/Index`
- **What**: Grid of all your skills with stats
- **Actions**: Create, View Dashboard, Delete

### Skill Dashboard
- **URL**: `/SkillRoadmap/Dashboard/{id}`
- **What**: Main hub with charts and today's task
- **Features**: Progress circle, stats, charts, one-tap completion

### Daily Tasks
- **URL**: `/SkillRoadmap/Tasks/{id}`
- **What**: Navigate through days, mark complete
- **Features**: Date navigation, task form, completion history
